# Slider-Image

Stunning HTML & CSS Card Animation

![Preview of Slider-Image](1712992879573.jpg)

A lightweight, responsive HTML & CSS demo showcasing a sliding image/card animation — no JavaScript required. Perfect as a codepen demo, portfolio piece, or UI inspiration.

## Demo

Open `index.html` in your browser (or use Live Server / a static host) to view the animation:

1. Clone the repo:

   git clone https://github.com/BinaryVortex/Slider-Image.git
2. Open `index.html` in your browser.

## Features

- Pure HTML & CSS implementation
- Smooth card/slider animation
- Responsive layout
- Multiple demo images included (space, digital, winter, global)

## Files

- `index.html` — demo markup
- `style.css` — styles and animations
- `1712992879573.jpg`, `digital.jpg`, `space.jpg`, `global.jpg`, `winter.jpg` — demo images

## Customize

- Replace the images in the HTML with your own to personalize the slider.
- Tweak timing and transforms in `style.css` to change animation speed and behavior.

## Usage ideas

- Add to your portfolio as a UI/UX sample
- Use as a header or feature card on landing pages
- Learn CSS animations and transforms by experimenting with the styles
